# eBike Display — полный проект LVGL Pro

Интерфейс ESP32, 480×320, русский язык и тёмная тема. PlatformIO собирает
экспорт этого проекта. `src/Ui.cpp` подключает реальные данные, действия,
касания и оптимизации отрисовки, не создавая отдельную копию макета.

## Работа в редакторе

1. Откройте эту папку через **Open UI Project**.
2. Откройте `screens/app.xml` — сборку всех четырёх представлений со свайпами.
3. Для отдельных экранов используйте `screens/dashboard.xml`, `settings.xml`,
   `diagnostics.xml`, `trip.xml`. Они используют те же компоненты, что и `app`.
4. Геометрию и оформление меняйте в `components/*_view.xml` через Code/Design.
   `globals.xml` содержит палитру, стили, шрифты и изображения.
5. Сохраните файлы и выберите **Export code only** (Cmd+E). Обновятся
   `_gen.c/.h`, данные шрифтов/картинок и `file_list_gen.cmake`.
6. Из корня репозитория запустите `./flash.sh`.

Не переименовывайте именованные элементы, которые ищет `Ui::begin`,
без соответствующего изменения привязок. При отсутствии элемента инициализация
завершается ошибкой, доступной через USB/Wi-Fi.
Сгенерированные файлы вручную не редактируют. Экспорт хранится в Git,
поэтому для обычной сборки прошивки редактор не требуется.

## Экраны и действия

- `dashboard_view`: скорость, шкала, растровые индикаторы, температуры,
  карусели заряда и одометра с точками, аварийка, режимы и лимиты.
- `settings_view`: тайминги с кнопками +/−, переворот, управление VESC,
  круиз и сохранение. Список прокручивается вертикально.
- `diagnostics_view`: реальные сведения ESP/VESC и входов.
- `trip_view`: статистика поездки и график скорости за последнюю минуту.

Subjects `ui_*` дают локальный предпросмотр кнопок. Числа 42 км/ч, 82%,
температуры и пробег являются примерами. В прошивке они очищаются до
включения подсветки, затем заменяются данными VESC. Предпросмотр не имеет
связи с контроллером или SD.

ESP32 заменяет действия предпросмотра существующими обработчиками:
подтверждение режимов/лимитов, безопасный режим, запрет настроек при движении,
сохранение и работа пульта остаются в основном приложении.
Карусели используют нативный Tabview; полные страницы на ESP32 переключаются
без анимации. Шкала из XML кэшируется в A8, перерисовывается только стрелка.
Для вложенного дерева компонентов стек основной задачи ESP32 увеличен до 24 КБ.

## Версии и ресурсы

На 26.10.2026 установлены последние стабильные LVGL Pro 2.0.5, LVGL 9.6.0,
Arduino_GFX 1.6.9, ArduinoJson 7.4.3 и PlatformIO espressif32 8.0.0.
LVGL Pro 2.0.5 включает движок предпросмотра 9.5.0, поэтому `project.xml`
оставлен на 9.5.0. Прошивка и `sim/CMakeLists.txt` используют 9.6.0;
экспорт проверяется на этой версии. Указание 9.6.0 в XML пока не обновляет
движок редактора. Версия Pro 2.1 beta не устанавливается автоматически.

Фон и иконки — PNG в `images/`, экспорт RGB565/A8 входит в прошивку.
Шрифты находятся в `fonts/`, лицензия — `fonts/OFL.txt`.
`tools/convert_background.py` и `tools/prepare_icons.py` обновляют также
PNG проекта Pro; после них повторите экспорт. Диапазоны символов шрифтов
в XML разделяются запятыми.

Проверки из корня проекта:

```sh
sh tools/test.sh
python3 tools/render_ui.py
pio run
```

Рендер использует тот же экспорт и backend, проверяет четыре страницы,
свайпы, точки каруселей, настройки, переворот касаний и отсутствие лишней
перерисовки. Изображения проверки записываются в игнорируемую папку `build/`.


## Скругления, карусели и переключатели

В `components/dashboard_view.xml` у `battery_card` и `trip_card` включён
`style_clip_corner="true"`: это обрезает дочерние элементы по скруглению
рамки. Одного `radius` недостаточно. Вложенные `battery_pages` и `trip_pages`
занимают 100% внутренней области рамки и имеют собственное скругление.
В редакторе выбирайте именно рамку, затем свойство **Clip corner** в стилях.

LVGL создаёт у Tabview внутренний контейнер содержимого, который редактор
9.5 не выводит отдельным элементом. Его белый фон убирается в `Ui::begin`.
Там же отключена упругая прокрутка за край. `Ui::carouselSwipe` переключает
три страницы по кругу в обе стороны, сохраняя выбор одометра. При переходе
с последней на первую нет обратной прокрутки через промежуточные страницы.
Циклические жесты реализованы в ESP32 backend; предпросмотр редактора
продолжает использовать стандартный Tabview.

Форма переключателей задана в `globals.xml`: `switch_track`,
`switch_indicator`, `switch_on`, `switch_knob`. Дорожка и бегунок имеют
скругление, бегунок светлый, включённая дорожка голубая. Стили применены
ко всем трём переключателям в `components/settings_view.xml` и не зависят
от стандартной темы редактора.


## Метрики шрифта показаний

Предпросмотр редактора использует TTF/FreeType, а `lv_font_conv` при экспорте
сокращает высоту строки по выбранным символам. Для `ui_value` размером 32 px
это давало 33/8 вместо TTF-метрик 44/10 (`line_height`/`base_line`), поэтому
заряд и пробег оказывались выше при одинаковой координате Y.

`tools/pro_font_metrics.py` читает TTF, указанный в `globals.xml`, и формирует
`fonts/ui_value_metrics.h`. PlatformIO и host-рендер вызывают его автоматически.
В пользовательском `ebike_display.c` применяется копия дескриптора шрифта с
этими метриками. Константные данные во flash и файлы `_gen` не изменяются.
Исправление сохраняется после экспорта и учитывает изменение размера `ui_value`.
Для цифр спидометра `ui_speed` применяется такая же нормализация: при 72 px метрики TTF равны 98/22 вместо экспортированных 54/1.
Подписи `ui_small` и `ui_medium` этим изменением не затрагиваются.


## Поведение касаний и тема

Прошивка явно использует Simple theme (`LV_USE_THEME_DEFAULT=0`), как XML-проект.
Недостаточно включить `LV_USE_THEME_SIMPLE`: при включённой Default LVGL
выбирает её первой и добавляет отсутствующие в макете стили состояний.
У внешних Tabview и панелей точек отключена самостоятельная прокрутка:
свайп не должен перехватываться контейнером вместо переключения карточки.
Для жестов задан порог 16 px и минимальная скорость 1 px за опрос.

У кнопки аварийки рамка всегда занимает 2 px, значок выровнен по центру,
поэтому при активации не меняется его позиция. Переключатели используют
A8-маски дорожки 66×34 и бегунка 26×26, рассчитанные с восьмикратным
сглаживанием (`tools/prepare_switches.py`), затем экспортированные через Pro.
