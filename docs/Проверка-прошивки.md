# Результаты локальной проверки — 25.10.2026

## Проверено

- Сборка PlatformIO для собственной записи платы `jc3248w535`, ESP32-S3 N16R8.
  Arduino ESP32 2.0.17, GFX 1.6.0, LVGL 8.3.11, ArduinoJson 7.4.2.
- Тесты `sh tools/test.sh` с AddressSanitizer и UndefinedBehaviorSanitizer:
  модель света/режимов/поворотов, неоднозначные резистивные сочетания,
  двойное/длинное нажатие и отмена, переполнение millis, CRC и восстановление
  пакетов, проверка формата телеметрии, отсутствие моторных команд по умолчанию,
  версия VESC, сохранение лимитов рекуперации, подтверждение чтением обратно,
  запрет переключения с нажатым газом, подтверждение профиля по токену,
  круиз/потеря телеметрии. Всё прошло.
- Тест SD с настоящим ArduinoJson и файловым мок-адаптером: восстановление
  последнего целого снимка после частичной записи, восстановление только
  постоянных полей, проверка JSON и запуск без SD. Всё прошло.
- `python3 tools/render_ui.py`: реальные виджеты LVGL отрисованы в 480×320,
  проверены переключение страниц и изменение реального поля тайминга.
  PNG главного экрана, настроек, диагностики и активных индикаторов сохранены
  в `screenshots/`; просмотрены визуально, шрифты/подписи помещаются.
- По замечанию пользователя заменены примитивы иконок на сгенерированные растры.
  Проверены прозрачность, состояния, зеркальность поворотников и центровка
  видимых границ (отклонение не более 0.5 px); все семь индикаторов верхнего ряда
  имеют общую центральную линию и одинаковый шаг.
- Упакованы приложение для OTA и объединённый образ для первого USB-запуска.
  SHA256 и размеры записаны в `dist/manifest.json`.

Значения скорости 42 км/ч, батареи 82%, пробега 24.8 км и температур на PNG
подаются только в отдельном host-тесте компоновки. В прошивке их нет.

## Что ещё требует аппаратного стенда

- LCD/тач и их ориентация, реальная работа PSRAM и SD.
- GPIO разъёмов и направление кабеля, уровень сигналов и реальная скорость UART.
- Формат ответов конкретной сборки Flipsky 7.0, SI-телеметрия, исходные лимиты.
- Реальная нейтраль с газом/PAS, сохранение торможения, плавность Drive/Sport,
  ограничения скорости и все переходы круиза.
- Синтаксис/исполнение временного обработчика круиза на реальном LispBM
  и отмена по тормозу/обрыву UART/выключению ESP. Наличие исходников и
  host-тест транспорта не заменяет этот запуск.
- Калибровка пульта, точность/шум АЦП и отбрасывание мультинажатий.
- MCP/ADS с реальной платой, нагрузками и помехами; порог DIAG 78 пока стендовый.
- OTA, пропадание питания при записи SD, длительная работа и задержки опроса
  при работе SD/HTTP. Текущая интеграция кооперативная; реальные максимальные
  задержки и поведение клаксона/поворотов при медленной SD ещё не измерены.

ESP не обнаружен среди доступных USB-портов. Запись устройства не выполнялась.
Моторные команды и круиз выключены по умолчанию. Текущая сборка предназначена
для первичного стенда, а не является подтверждённой дорожной прошивкой.
