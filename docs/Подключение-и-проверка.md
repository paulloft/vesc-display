# Подключение JC3248W535

Соответствия ниже взяты из схемы и таблицы GPIO JC3248W535; проверить маркировку
и ориентацию на конкретной плате. Нумерация разъёма — не вид со стороны кабеля.
Не переносить эти номера на заводской разъём Flipsky.

## Дисплей ↔ Flipsky

| Разъём дисплея | Сигнал | GPIO ESP | Соединение |
|---|---|---:|---|
| P1.1 | +5VIN | — | +5V контроллера |
| P1.2 | TX | 43 | RX контроллера |
| P1.3 | RX | 44 | TX контроллера |
| P1.4 | GND | — | GND контроллера |

TX/RX — логика 3.3 В; контакт питания +5V не означает 5-вольтовую логику.
Это UART общего назначения; программа использует UART1 с маршрутизацией
на GPIO43/44. USB-C остаётся интерфейсом прошивки и логирования.
Для первого стенда питать от одного источника; не соединять два независимых
выхода +5V от USB и контроллера без проверки схемы питания.

Скорость UART фиксирована: 115200 бод, 8N1. Перебор скоростей отключён.
До распознавания отправляются только запросы чтения.

## Собственная плата

| ESP / разъём дисплея | Собственная плата DISPLAY1 |
|---|---|
| GPIO18, P3/P4.4 | 2 PCF/SCL |
| GPIO17, P3/P4.3 | 3 PCF/SDA |
| P1.1 +5VIN | 1 +5V |
| P1.2 TX | линия RX Flipsky после проверки кабеля |
| P1.3 RX | линия TX Flipsky после проверки кабеля |
| GND | 8 GND |

P3 и P4 электрически дублируются: 1 GND, 2 3.3V, 3 GPIO17, 4 GPIO18.
Внешний I²C отдельный от шины тача GPIO4/8. Подтяжки на собственной плате уже
4.7 кОм к 3.3 В. Адреса: MCP23008 0x20, ADS7830 0x48. GPIO7 MCP остаётся LOW.
ADC3 контроллера в первой версии не используется.

## Пульт Z930

| Линия пульта | Подключение дисплея |
|---|---|
| Общая | GND |
| Резистивная | P2.2 GPIO6 **и перемычка к P2.7 GPIO9** |
| Power | P2.3 GPIO7 |
| M | P2.4 GPIO15 |

Внешний резистор не нужен. **Соединить GPIO6 с GPIO9 перемычкой** и подключить
к этой общей точке резистивную линию пульта. GPIO9 настроен только как
INPUT_PULLUP (типично 45 кОм к 3.3 В), GPIO6 измеряет напряжение АЦП.
Не подключать эту линию напрямую к 3.3 В или 5 В. Резисторы кнопок замыкаются
на GND. Power/M настроены как INPUT_PULLUP. GPIO5 не используется: он занят
штатным измерением аккумулятора дисплея. GPIO46 не используется как выход.

Измеренные уровни для подключённого экземпляра Z930 и дисплея:

| Кнопка | Сопротивление кнопки | Эталон АЦП |
|---|---:|---:|
| Свет | 3.2 кОм | 217 мВ |
| Круиз | 5 кОм | 338 мВ |
| Левый | 19.9 кОм | 1259 мВ |
| Правый | 9.9 кОм | 662 мВ |
| Клаксон | 1 кОм | 54 мВ |

Распознавание использует таблицу `config.key_mv` в этом порядке. Эти значения
также являются начальными значениями профиля этого дисплея, поэтому без SD
не теряется возможность пользоваться пультом. На другом экземпляре нужны
собственные замеры. Таблица сохраняется на SD; `key_ohms` остаётся номиналами
резисторов, а показание R в диагностике — оценкой по калибровочным точкам.
Одним точным резистором внутреннюю подтяжку в этом экземпляре описать не удалось.
`key_pullup_ohms` используется только в старом режиме расчёта, который включается
таблицей `key_mv: [0,0,0,0,0]`.

АЦП настроен на 6 dB, GPIO6/ADC1 channel 5, после запуска остальных GPIO.
Отпущенная линия насыщает АЦП: у проверенного чипа это 1816 мВ, **не фактическое
напряжение линии 3.3 В**. Насыщение распознаётся как отсутствие нажатия.
Каждые 5 мс выполняются предварительное преобразование, девять измерений,
усечённое среднее центральных пяти и медиана пяти временных отсчётов.
Окно начала нажатия: ±2.5% от эталона, минимум ±3 мВ. После подтверждённого
нажатия действует окно удержания ±5%, минимум ±5 мВ. Оно не используется для
начала нового нажатия и не задерживает отпускание. Одиночный некорректный
отсчёт не отменяет жест; устойчивое неизвестное значение отменяет через 20 мс.
Произвольные сочетания кнопок не поддерживаются: некоторые комбинации
электрически неотличимы от одиночной кнопки.

Диагностика показывает сглаженное напряжение, напряжение текущего пакета
(`key_raw_mv`) и его полный размах (`key_noise_mv`). При загрузке GPIO9 временно
переключается только между входами с подтяжкой вниз/вверх, затем остаётся
INPUT_PULLUP. При отпущенных кнопках GPIO6 должен следовать: около 0 мВ / насыщение.
Это проверка проводки, а не калибровка нажатых кнопок.

По USB команда `d` возвращает JSON. Строка JSON с переводом строки применяет
настройки через общую проверку и сохраняет на SD, например:
`{"key_mv":[217,338,1259,662,54]}`. Изменения принимаются только в остановленном N
или в стендовом N с выключенными моторными командами; JSON не может включить
управление без выполнения обычных условий допуска.

Многократные измерения для снижения шума рекомендует и
[Espressif](https://docs.espressif.com/projects/esp-idf/en/v4.4.5/esp32s3/api-reference/peripherals/adc.html#minimizing-noise).

## Стендовая последовательность

1. USB: проверить LCD, ориентацию тача, все три страницы и изменение таймингов.
2. SD: сохранить настройку, перезапустить, затем проверить запуск без карты.
3. UART: без моторных команд проверить версию 7.0, скорость, SOC, температуры,
   газ/тормоз в диагностике и отсутствие свежих показаний при отключении связи.
4. Пульт: пять одиночных кнопок, Power/M, удержание и двойной клик.
5. После изготовления платы: ACK MCP/ADS, выходы по одному, бит тормоза,
   диагностические raw, реальная полярность, пусковые токи и порог аварии.
   Код 78 — стартовый стендовый порог, его нужно подтвердить измерениями.
6. Моторные команды испытывать с вывешенным колесом: N, сохранение торможения,
   Drive/Sport, пределы скорости, работа PAS, повторный запуск и обрыв UART.
7. Отдельно проверить круиз: удержание исходной скорости, газ с возвратом,
   отмена тормозом/кнопкой, отключение UART и ESP. Не считать эти проверки
   выполненными по результатам компиляции или host-тестов.
